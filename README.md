# AI Bubble Watch

Live dashboard tracking AI-market bubble risk with separate sentiment/reflexivity and fundamental-risk scores.

## Signals
- AI and semiconductor price reflexivity
- VIX / volatility regime
- AI-bubble news narrative pressure
- Mega-cap fundamental confirmation proxy
- Buy-the-dip to sell-the-bounce regime proxy

Built for Vercel using a static dashboard and a serverless `/api/data` endpoint.
